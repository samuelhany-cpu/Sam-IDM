# Quick Start Guide

Get started with Sam Download Manager in 5 minutes!

## Installation

### Option 1: Installer (Recommended)
1. Download `Sam-Download-Manager-Setup-1.0.0.exe` from the Releases page
2. Run the installer
3. Follow the installation wizard
4. Launch Sam from Start Menu or Desktop

### Option 2: Portable Version
1. Download `Sam-Download-Manager-Portable.zip`
2. Extract to a folder
3. Run `Sam Download Manager.exe`

## First Launch

When you first launch Sam:

1. **Choose Download Location**
   - Default: `C:\Users\YourName\Downloads`
   - Files will be organized into category folders

2. **Set Concurrent Downloads**
   - Recommended: 3 downloads at a time
   - Adjust in Settings if needed

## Add Your First Download

### Method 1: Direct URL
1. Click the **+ Add** button in the toolbar
2. Paste the download URL
3. (Optional) Customize the filename
4. Click **Add Download**
5. Watch it download! 📥

### Method 2: Browser Integration
1. Install the Chrome extension (see below)
2. Click any download link in your browser
3. Sam will intercept it and ask what to do
4. Choose "Download Now" or "Download Later"

## Install Browser Extension

### Chrome/Edge Setup
1. Open `chrome://extensions/` (or `edge://extensions/`)
2. Enable **Developer mode** (toggle in top-right)
3. Click **Load unpacked**
4. Navigate to Sam's installation folder
5. Select the `browser-extension` folder
6. Done! 🎉

**Where is Sam installed?**
- Default: `C:\Program Files\Sam Download Manager\`
- Or check Start Menu shortcut properties

### Verify Extension Works
1. Go to any website with download links
2. Click a download link
3. Sam should intercept it and show a dialog
4. If not, make sure Sam is running!

## Key Features

### Pause & Resume
- Click the **⏸ Pause** button on any download
- Click **▶ Resume** to continue
- Downloads resume from where they left off

### Dark Mode 🌙
- Click the moon/sun icon in the toolbar
- Your preference is saved automatically
- All dialogs support dark mode

### Multi-Select Delete
1. Check the boxes next to downloads
2. Click **Delete (N)** button
3. Confirm deletion
4. Selected items are removed

### Sort Your Downloads
- Click any column header to sort
- Click again to reverse order
- Sort by: Name, Size, Progress, Speed, Status, Date

### Filter Downloads
- **All**: Show everything
- **Downloading**: Only active downloads
- **Completed**: Finished downloads
- **Paused**: Paused downloads

### File Organization
Sam automatically organizes files into folders:
- 📦 **Compressed**: zip, rar, 7z, etc.
- 🎵 **Music**: mp3, wav, flac, etc.
- 🎬 **Video**: mp4, mkv, avi, etc.
- 🖼️ **Images**: jpg, png, gif, etc.
- 📄 **Documents**: pdf, doc, xls, etc.
- 💻 **Programs**: exe, msi, etc.
- And more!

## System Tray

### Minimize to Tray
- Click the minimize button
- Sam stays in system tray
- Click tray icon to restore

### Tray Menu
Right-click the tray icon for:
- Start All Downloads
- Pause All Downloads
- Exit

## Download Scheduler

Schedule when downloads should run:

1. Click **⏰ Schedule** in toolbar
2. Set start time (e.g., 11:00 PM)
3. Set end time (e.g., 7:00 AM)
4. Choose days of the week
5. Enable the scheduler
6. Downloads only run during scheduled hours

**Use case:** Download large files overnight when bandwidth is cheaper or faster.

## Settings

Click **⚙ Settings** to configure:

### General
- **Download Path**: Where files are saved
- **Concurrent Downloads**: How many at once (1-10)
- **Auto-start**: Launch Sam on Windows startup

### Downloads
- **Segments**: Parallel connections per file (1-8)
- **Retry Attempts**: How many times to retry (1-10)
- **Timeout**: Connection timeout in seconds

### Categories
- Enable/disable automatic categorization
- Customize folder names (future feature)

## Troubleshooting

### Download Won't Start
- Check your internet connection
- Verify the URL is correct
- Try pausing and resuming
- Check firewall settings

### Browser Extension Not Working
- Make sure Sam is running
- Check extension is enabled in Chrome
- Reload the extension
- Check Sam's console for errors

### Port 8765 Already in Use
- Another app is using the port
- Close other apps or restart computer
- Sam will show an error in the console

### Downloads Are Slow
- Increase segments per download in Settings
- Check your internet speed
- Pause other downloads
- Some servers limit speed

### Dark Mode Not Working
- Try toggling it off and on
- Restart Sam
- Check localStorage is enabled

## Tips & Tricks

### Faster Downloads
1. Increase segments to 8 in Settings
2. Reduce concurrent downloads to 1-2
3. Use wired connection instead of WiFi
4. Download during off-peak hours

### Organize Downloads
- Let Sam auto-categorize your files
- Files go into appropriate folders
- Easy to find what you need
- Keeps Downloads folder clean

### Batch Downloads
1. Add multiple URLs at once
2. They'll queue automatically
3. Process in order
4. Monitor progress

### Schedule Large Downloads
1. Add downloads but pause them
2. Set scheduler for nighttime
3. Enable scheduler
4. Let it run overnight
